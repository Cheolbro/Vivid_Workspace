# FX 카탈로그 (fx_catalog.txt)
> **[자동 관리 파일]** `src/components/fx/`에 컴포넌트 추가/삭제 시 즉시 업데이트 필수.
> 제미나이가 `remotion_plan.json` 작성 시 이 파일을 참조하여 `effect.type` 값을 결정합니다.

---

## ★ Gemini용 JSON 작성 규칙 (필독 — 이 규칙을 어기면 렌더링 오류 발생)

### 규칙 1: `type` 필드 값 결정

| 상황 | `type` 값 | 예시 |
|---|---|---|
| 카탈로그에 등록된 효과 사용 시 | 컴포넌트 이름 **그대로** | `"GoldenRayFX"`, `"HighlighterFX"` |
| Popup 내장 컴포넌트 사용 시 | `"Popup"` 고정 | `"Popup"` |
| 카탈로그에 **없는** 완전히 새 효과만 | `"Custom"` + `description` 상세 기술 | — |

> `"Custom"` 은 이 카탈로그에 없는 신규 효과 전용. 기등록 효과에 `"Custom"` 쓰면 불필요한 재코딩 발생.

### 규칙 2: props 위치 (★ 가장 많이 실수하는 부분)

**Popup 타입:**
```json
{ "type": "Popup", "src": "image_1.jpeg", "text": "설명", "commonProps": { "x": 0, "y": 0 } }
```
→ `src`, `text` 는 **최상위**에 작성.

**FX 컴포넌트 타입 (HighlighterFX, TypewriterFX 등 카탈로그 등록 효과):**
```json
{
  "type": "HighlighterFX",
  "commonProps": { "x": -350, "y": -200, "fontSize": "80px" },
  "specificProps": { "text": "강조할 텍스트", "highlightColor": "#FFE500" }
}
```
→ `text` 를 포함한 **모든 FX 고유 props는 `specificProps` 안**에 작성.
→ `x`, `y`, `fontSize` 는 `commonProps` 에 작성.
→ **최상위에 `text` 절대 금지** (Popup 규칙과 혼용 금지).

> 모두 `spring` / `interpolate` / `useCurrentFrame` Remotion 네이티브 방식.

> **★ T01·T03·T05는 All-in-One 시퀀스**: `revealStyle` prop으로 텍스트 등장(Step1) → 효과 발동(Step2)이 단일 컴포넌트 안에서 순차 진행.

## 사용 예시 (remotion_plan.json 작성 형식)

```json
{
  "effects": [
    {
      "id": "p1_1_fx",
      "type": "Popup",
      "src": "image_1.jpeg",
      "startFrame": 90,
      "durationFrames": 60,
      "commonProps": { "width": "70%", "maxHeight": "70%" }
    },
    {
      "id": "p1_2_fx",
      "type": "GoldenRayFX",
      "startFrame": 150,
      "durationFrames": 120,
      "commonProps": { "x": 0, "y": 100 },
      "specificProps": { "rayCount": 8, "color": "#FFD700" }
    },
    {
      "id": "p2_1_fx",
      "type": "FocusRingFX",
      "startFrame": 0,
      "durationFrames": 180,
      "commonProps": { "x": 300, "y": -100 },
      "specificProps": { "ringColor": "#FF3333", "maxSize": 150 }
    },
    {
      "id": "p3_1_fx",
      "type": "Custom",
      "description": "폭발하는 원유 파이프라인 위로 불꽃이 치솟는 파티클 효과 (아직 카탈로그에 없는 신규 효과)",
      "startFrame": 60,
      "durationFrames": 90,
      "commonProps": { "x": 0, "y": 0 },
      "specificProps": {}
    }
  ]
}
```
