# FX 카탈로그 (fx_catalog.txt) — Opal System Standard
> **[시스템 연동용]** 이 카탈로그의 규칙은 `remotion_plan_creation_opal.json`의 생성 로직과 완벽히 일치해야 합니다.
> 제미나이가 `remotion_plan.json` 작성 시 이 파일의 규칙을 최우선으로 따릅니다.

---

## ★ JSON 작성 규칙 (Opal System Schema)

### 규칙 1: `type` 필드 값 결정
- 카탈로그 FX 사용 시: 컴포넌트 이름 **그대로** (예: `"LossChart3DFX"`, `"HighlighterFX"`)
- 일반 텍스트 사용 시: `"Popup"` 고정
- 이미지 배경 사용 시: `"Image"` 고정

### 규칙 2: 속성(Props) 분리 작성 (중요)
모든 요소는 공통 속성과 전용 속성으로 분리하여 작성합니다.
- `commonProps`: `x`, `y`, `scale`, `width`, `fontSize` 등 위치와 크기 관련.
- `specificProps`: 해당 FX에만 있는 고유 설정값. (없을 경우 `{}` 빈 객체 필수, 이 경우 채우지 말 것)
- **시간 단위**: 모든 타이밍은 초(s)가 아닌 **프레임(Frames, 30fps 기준)** 단위를 사용합니다. (`startFrame`, `durationFrames`)

### 규칙 3: Image 배경 필수 요소
- `src`: 배경 이미지 파일명 필수 (예: `"image_1.jpeg"`)
- `kenBurns` 객체가 반드시 포함되어야 합니다.
- 패턴: `zoom-center`, `pan-right`, `pan-left`, `zoom-out`, `pan-up`, `pan-down`

### 규칙 4: Popup(텍스트) 필수 요소
- `animation`: `in`, `inDurationFrames`, `out`, `outDurationFrames`, `easing` 필드 필수.
  - `in` 유효값: `slideFromLeft` | `slideFromRight` | `slideFromBottom` | `slideFromTop` | `fadeIn` | `scaleUp` | `typewriter` | `revealMask`
  - `out` 유효값: `fadeOut` | `scaleDown` | `none`
  - `easing` 유효값: `easeOutBack` | `easeOutExpo` | `easeInOutSine` | `linear`
- `textStyle`: `color`, `fontWeight`, `shadow`, `background` 필드 필수.
- **텍스트 배경은 반드시 투명**: `background: "transparent"`, `backgroundPadding: "0px"`, `borderRadius: "0px"`
- **Sync-Exit 필수**: 같은 슬라이드의 모든 텍스트/FX는 `startFrame + durationFrames` 합산이 슬라이드 종료 프레임과 일치해야 합니다. 텍스트마다 `startFrame`을 다르게 설정하고, `durationFrames`는 각자 슬라이드 종료 프레임 기준으로 역산합니다.

## 3. 사용 예시 (remotion_plan.json 규격)
> Opal 시스템이 최종 병합(Merger) 전 출력하는 개별 객체 형식입니다.
> **Sync-Exit 규칙**: 슬라이드 종료 프레임이 300이면, 30프레임에 등장하는 텍스트의 durationFrames = 270, 60프레임에 등장하는 텍스트의 durationFrames = 240.

```json
  {
    "id": "p1_1_bg",
    "type": "Image",
    "src": "image_1.jpeg",
    "startFrame": 0,
    "durationFrames": 300,
    "commonProps": { "width": "100%", "height": "100%" },
    "kenBurns": {
      "startScale": 1.0, "endScale": 1.15,
      "startX": 0, "endX": -30,
      "easing": "easeInOutSine"
    }
  },
  {
    "id": "p1_2_fx",
    "type": "GrowthChart3DFX",
    "startFrame": 30,
    "durationFrames": 270,
    "commonProps": { "x": 400, "y": -200, "scale": 1.5 },
    "specificProps": {}
  },
  {
    "id": "p1_3_txt",
    "type": "Popup",
    "text": "경제 성장률 5% 달성",
    "startFrame": 60,
    "durationFrames": 240,
    "commonProps": { "x": 0, "y": 200, "fontSize": "100px" },
    "animation": {
      "in": "scaleUp", "inDurationFrames": 20,
      "out": "fadeOut", "outDurationFrames": 15,
      "easing": "easeOutBack"
    },
    "textStyle": {
      "color": "#FFFFFF", "fontWeight": "800",
      "shadow": "0 4px 20px rgba(0,0,0,0.5)",
      "background": "transparent"
    }
  },
  {
    "id": "p1_4_txt",
    "type": "Popup",
    "text": "역대 최고 기록",
    "startFrame": 120,
    "durationFrames": 180,
    "commonProps": { "x": 0, "y": 320, "fontSize": "80px" },
    "animation": {
      "in": "slideFromBottom", "inDurationFrames": 15,
      "out": "fadeOut", "outDurationFrames": 15,
      "easing": "easeOutExpo"
    },
    "textStyle": {
      "color": "#FFD700", "fontWeight": "700",
      "shadow": "0 2px 12px rgba(0,0,0,0.7)",
      "background": "transparent"
    }
  }
```
